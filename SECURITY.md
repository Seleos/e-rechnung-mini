# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use "Report a vulnerability" on the Security
tab of the GitHub repository instead. The report stays private until a fix is available.

Tell us what is affected, how to reproduce it and what an attacker could do. You will get an answer
within a few working days.

## Supported versions

Only the latest release receives fixes.

## What the app does with your data

The app works on local files only. It does not send invoice, customer or company data anywhere and has
no update check or telemetry.
